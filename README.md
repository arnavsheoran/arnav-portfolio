# Arnav Sheoran — Portfolio Website

A responsive, static portfolio website built with HTML, CSS and JavaScript. It is ready to publish using GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `arnav-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. Your public URL will look like:
   `https://YOUR-USERNAME.github.io/arnav-portfolio/`

For a user/organization site repository named `YOUR-USERNAME.github.io`, the URL is:
`https://YOUR-USERNAME.github.io/`

## Before publishing
- Check that the phone number, email and LinkedIn URL are correct.
- Add your GitHub profile link if you want it displayed.
- Replace the abstract project illustrations with real project photos when available.
- If you add a résumé download, put the PDF in this folder and link it from `index.html`.

The site currently uses Google Fonts from a CDN; the rest of the site is static and requires no build tools.
